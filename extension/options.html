configurações da extensão

Backend

Rode npm run serve no projeto TRACECON. A extensão só funciona contra esse backend local.

Sinais automáticos

Auto-atualizar não opera. Apenas atualiza o sinal na down-bar. Você decide.

Parâmetros de análise

Sobre

TRACE/CON é uma ferramenta de análise, não é corretora e não executa ordens. A extensão lê o sinal do backend TRACECON local e mostra na down-bar. Você clica o botão BUY/SELL na corretora quando decidir.
