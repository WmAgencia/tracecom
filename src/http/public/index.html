        Extensão

        A TRACECON tem uma extensão de navegador (MV3) que abre um Side Panel ao lado da sua corretora (TradingView, Binance, Exodus). Ela consome esta mesma API em http://127.0.0.1:8788.

        Baixar extensão (.zip) —

        1. Baixe o .zip acima e descompacte em qualquer pasta.
        2. Abra chrome://extensions (ou equivalente no seu navegador).
        3. Ative o Modo do desenvolvedor (canto superior direito).
        4. Clique em Carregar sem compactação e selecione a pasta descompactada.
        5. Com este backend rodando (npm run serve), clique no ícone da TRACECON → Side Panel.

        A extensão só funciona contra um servidor TRACECON rodando localmente. Permissões solicitadas: sidePanel, storage, tabs.
