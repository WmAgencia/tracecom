distribuição Extensão do navegador

Um Side Panel que abre ao lado da sua corretora (TradingView, Binance, Exodus), consumindo esta mesma API em http://127.0.0.1:8788.

Baixar extensão (.zip) —
  1. Baixe o .zip acima e descompacte em qualquer pasta.
  2. Abra chrome://extensions (ou equivalente no seu navegador).
  3. Ative o Modo do desenvolvedor (canto superior direito).
  4. Clique em Carregar sem compactação e selecione a pasta descompactada.
  5. Com o backend local rodando (npm run serve), clique no ícone → Side Panel.

A extensão só funciona contra um servidor TRACECON local. Permissões: sidePanel, storage, tabs.
